| 字段 | 类型 | 必填 | 校验 / 说明 |
| --- | --- | --- | --- |
| doctorId | Long | 是 | @NotNull；医生须存在（→4001） |

| timeSegment | String | 是 | 上午 / 下午；医生+日期+时段唯一（→5001） |
| totalQuota | Integer | 是 | @Min(1)，≤200；落库 left_quota=total_quota |
