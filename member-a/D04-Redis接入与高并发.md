## 3. 任务清单（按序执行）

1. 实现 RedisCacheService（StringRedisTemplate + JSON，TTL 1800s+随机抖动）
2. 实现 RedisSetnxLockService（setIfAbsent，30s 兜底过期，unlock 必须在 finally 中调用）
3. 实现 RedisCounterRateLimitService（INCR + EXPIRE 60s，超过 5 次拒绝）
4. 挂号编排插入：限流(3003) → 锁(3002，抢锁失败即拒) → 既有链路
5. yml his.middleware.redis.enabled=true 切换验证；关闭后 Noop 降级主流程仍可跑
6. 编写并发自测脚本（Apifox runner 或 curl 循环）
