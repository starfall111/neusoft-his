## 3. 任务清单（按序执行）

1. P3 首页：双挂号入口（当天挂号 / 预约挂号，V2.0 改版——首页不再平铺科室列表）
2. P4 科室选择页（父子分类，流程内）：GET /departments 平铺数据按 parentId 组两级——左栏父分类（parentId 为空的七类：内科/外科/妇儿/五官/皮肤/中医/其他）、右栏该父分类下子科室；五官/皮肤/中医/其他暂无子科室 → 右栏空态「该分类暂无科室」；点子科室带 deptId 进入号源页
3. P4A 当天挂号 / P4B 预约挂号：GET /quotas/days?deptId= 日期条三态（可约/已满/休，P4B 专属）；GET /quotas?deptId=&date= 医生号源卡（姓名/职称/擅长/时段/余号/挂号费，后端已排序先上午后下午、职称主任→副主任→主治，直接渲染）；leftQuota=0 行不可选
4. P5 排班总览：GET /schedules?deptId=（科室级，响应带医生字段）按医生分组渲染近 7 天（当天~+6）；leftQuota=0 显示『已满』置灰不可选、空数组显示『暂无排班』

### 当日 DTO 速览（权威定义：db/dto-contract.md，与本表同源生成；冲突以契约文件为准并提对齐，禁止私自加改字段）

**GET /departments（S4） · DepartmentRespDto（响应；V2.3 父子两级平铺，前端按 parentId 组两级）**

| 字段 | 类型 | 必填 | 校验 / 说明 |
| --- | --- | --- | --- |
| id | Long | 是 | dept.id |
| deptName | String | 是 | 科室名称，≤100 |
| deptCategory | String | 是 | 分类名称冗余：子科室=父分类名、父分类节点=自身名（后端按 parentId 维护） |
| parentId | Long | 否 | 父分类 id；NULL=自身为父分类节点（左栏七类）；仅两级，无孙级（V2.3 新增） |
| deptIntro | String | 否 | 简介，≤500 |

**GET /quotas?deptId=&date=（V2.3 新增，P4A/P4B 医生号源卡） · QuotaRespDto（响应，List）**

| 字段 | 类型 | 必填 | 校验 / 说明 |
| --- | --- | --- | --- |
| scheduleId | Long | 是 | schedule.id；挂号时作为 scheduleId 传入 POST /registrations |
| doctorId | Long | 是 | doctor.id |
| doctorName | String | 是 | 医生姓名 |
| title | String | 是 | 职称中文直传 |
| skill | String | 否 | 擅长领域 |
| timeSegment | String | 是 | 上午 / 下午；后端已排序先上午后下午、时段内职称主任→副主任→主治，前端直接渲染 |
| leftQuota | Integer | 是 | 剩余号源；=0 该行不可选 |
| registerFee | BigDecimal | 是 | 挂号费（确认页费用展示来源，前端不做价格映射） |

**GET /quotas/days?deptId=（V2.3 新增，P4B 日期条） · QuotaDayRespDto（响应，List）**

| 字段 | 类型 | 必填 | 校验 / 说明 |
| --- | --- | --- | --- |
| date | LocalDate | 是 | yyyy-MM-dd；当天+1~+7 共 7 天 |
| dayStatus | String | 是 | 可约 / 已满 / 休（三态中文直传；「休」日期条置灰不可点） |

**GET /schedules（S6，doctorId 与 deptId 二选一；P5 用 deptId，窗口当天~当天+6） · ScheduleRespDto（响应）**

| 字段 | 类型 | 必填 | 校验 / 说明 |
| --- | --- | --- | --- |
| id | Long | 是 | schedule.id；挂号时作为 scheduleId 传入 POST /registrations |
| doctorId | Long | 是 | doctor.id（V1.9 新增；deptId 查询时前端按医生分组渲染） |
| doctorName | String | 是 | 联查 doctor 带出（V1.9 新增） |
| title | String | 是 | 职称中文直传（V1.9 新增） |
| workDate | LocalDate | 是 | 出诊日期 yyyy-MM-dd |
| timeSegment | String | 是 | 上午 / 下午（中文直传） |
| totalQuota | Integer | 是 | 号源总数 |
| leftQuota | Integer | 是 | 剩余号源；=0 时前端显示「已满」置灰不可选 |
