### 当日 DTO 速览（权威定义：db/dto-contract.md，与本表同源生成；冲突以契约文件为准并提对齐，禁止私自加改字段）

**GET /messages（P11 消息分页） · MessageRespDto（响应，PageDTO 包装）**

| 字段 | 类型 | 必填 | 校验 / 说明 |
| --- | --- | --- | --- |
| id | Long | 是 | site_message.id |
| title | String | 是 | ≤100；未读加粗 |
| content | String | 是 | ≤500；列表最多 2 行截断，点击展开 |
| msgType | String | 是 | 挂号成功 / 挂号已取消 / 系统通知（标签配色） |
| orderNo | String | 否 | 关联订单号；系统公告为 null |
| isRead | Integer | 是 | 0 未读（圆点）/ 1 已读（置灰） |
| createTime | LocalDateTime | 是 | 倒序；显示格式见任务清单 |

**GET /messages/unread-count**：`Result<Integer>`（铃铛 badge）；**POST /messages/{id}/read**：4004 → Toast「消息不存在」；**POST /messages/read-all**：`Result<Void>`
