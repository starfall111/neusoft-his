┌──────────────────────────────┐
│  新增科室                  ✕  │
│  科室名称*  [________________] │  ≤100，必填

| 元素 | 字段/行为 | 说明 |
| --- | --- | --- |
| 表格列 | `id / deptName / deptCategory / deptIntro` | 分类列为父分类名称冗余（后端按 parentId 维护，管理端只读展示；可加 el-tag 装饰） |

| 保存 | POST / PUT 同一 Dialog（编辑时回填 + 隐藏 id；提交 deptName/parentId/deptIntro） | 成功 → `ElMessage.success` + 关弹窗 + **刷新当前页**（后端写时删缓存，App 端立即可见——演示点） |

| 错误 | 400（校验）/ 其他 → `ElMessage.error(message)` | |

## M4 全局规则（管理端）

| 项 | 规范 |
| --- | --- |
| axios 封装 | baseURL `http://localhost:8080/api`；请求拦截器注入 `Authorization: Bearer {token}`（token 来自 M5 登录，存 localStorage）；响应拦截器：`code===200` 透传 data，否则 `ElMessage.error(message)` 并 reject；HTTP 401 → `ElMessage.warning('登录已失效')` + 清 token + 跳 /login（V1.2 起） |
| 路由守卫 | 除 /login 外全部页面为受控页：无 token → 重定向 /login（与后端拦截器 /admin 前缀口径一致） |
| 网络异常 | 请求 reject 且无 response → `ElMessage.error('网络连接异常，请检查网络')` |
| 类型定义 | `src/api/` 集中定义：接口函数 + TS 类型（从 dto-contract.md 逐字段抄写；M6 统计组定稿后仍独立放 `src/api/stats.ts`，六接口类型从 mock-data.md V2.4 §4 逐字段抄写，无待对齐标记）；组件禁止手写 URL/字段（规则八） |
| 加载 | 表格 v-loading；Dialog 保存按钮 loading；禁止双层 loading |
| 表单校验 | rules 与 dto-contract 校验列一致（必填/长度/枚举下拉）；后端 400 时以 message 为准展示 |
| 空态 | 表格自带 el-empty；筛选无结果同空态；图表数据为空时整卡显示 el-empty |
| 刷新纪律 | 增/删/改成功后**刷新当前页**（保持 pageNum；删空当前页则 pageNum-1） |
