| 项目 | 内容 |
| --- | --- |
| 文档版本 | V1.1（2026-09-08：配合契约变更① 科室父子分类——M2 分类下拉改父分类动态下拉、保存改传 parentId；M3 科室下拉过滤子科室；随 dto-contract V1.3 / mock-data V2.3） |

> 技术基线：Vue3 + Element Plus + Vue Router + Pinia + axios；布局即"侧边菜单 + 顶栏 + 内容区"的常规后台框架，不追求视觉创新，追求**状态齐全、与契约零漂移**。管理端登录为范围外（401 → 提示页）。

## M2 科室管理页（S11）

**数据来源**：`GET / POST / PUT / DELETE /admin/departments`；列表 → `PageDTO<DepartmentRespDto>`（V1.1 起含 parentId）；保存 → `DepartmentSaveReqDto{deptName, parentId, deptIntro}`（V1.1：改传父分类 id，不再传分类文本）

```
┌──────────────────────────────────────────────┐
│ 科室管理                        [+ 新增科室]   │  页头：标题 + 主按钮
│ ┌──────────────────────────────────────────┐ │
│ │ ID │ 科室名称  │ 科室分类 │ 科室简介  │ 操作   │ │
│ │ 1  │ 心血管内科 │ 内科    │ 高血压、… │ 编辑 删除│ │  操作列固定右侧
│ │ 2  │ 消化内科   │ 内科    │ 胃肠疾病、…│ 编辑 删除│ │  简介 show-overflow-tooltip
│ │ …  │ 儿科      │ 妇儿    │ 儿童呼吸道…│ 编辑 删除│ │
│ └──────────────────────────────────────────┘ │
│                     ◀ 1 2 3 ▶   共 4 条  10条/页│  分页右下
└──────────────────────────────────────────────┘

[+ 新增科室] / [编辑] → Dialog（宽 520px）：
┌──────────────────────────────┐
│  新增科室                  ✕  │
│  科室名称*  [________________] │  ≤100，必填
│  父分类*    [内科        ▼]   │  下拉=父分类节点（GET /admin/departments 过滤 parentId 为空；七类预置）
│  科室简介   [____________]    │  textarea ≤500，选填
│              [取消]  [保 存]   │  保存带 loading
└──────────────────────────────┘
[删除] → ElMessageBox.confirm（type: warning）：
「删除后前台将不可见，是否继续？」[取消] [删除(danger)]
```

| 元素 | 字段/行为 | 说明 |
| --- | --- | --- |
| 表格列 | `id / deptName / deptCategory / deptIntro` | 分类列为父分类名称冗余（后端按 parentId 维护，管理端只读展示；可加 el-tag 装饰） |
| 分页 | `pageNum / pageSize` ↔ el-pagination；响应 `PageDTO{total, pageNum, pageSize, records}` | 删除当前页最后一条后回退一页 |
| 保存 | POST / PUT 同一 Dialog（编辑时回填 + 隐藏 id；提交 deptName/parentId/deptIntro） | 成功 → `ElMessage.success` + 关弹窗 + **刷新当前页**（后端写时删缓存，App 端立即可见——演示点） |
| 删除 | DELETE /{id}（逻辑删除 delmark=1） | 删除**父分类节点**时若其下仍有子科室 → 400「该分类下存在科室，无法删除」（后端校验，前端展示 message）；删除子科室不受限 |
| 错误 | 400（校验）/ 其他 → `ElMessage.error(message)` | |

**状态**：v-loading / el-empty（无数据）/ 错误 Message / 正常。

## M3 医生管理页（S12）

**数据来源**：`GET / POST / PUT / DELETE /admin/doctors`；列表 → `PageDTO<DoctorRespDto>`；保存 → `DoctorSaveReqDto{doctorName, deptId, title, skill}`

```
┌────────────────────────────────────────────────────┐
│ 医生管理    科室筛选[全部科室 ▼]（可选，待对齐） [+ 新增医生]│
│ ┌────────────────────────────────────────────────┐ │
│ │ ID │ 医生姓名 │ 所属科室  │ 职称     │ 擅长领域 │ 操作  │ │
│ │ 1  │ 周建国   │ 心血管内科 │ 主任医师 │ 冠心病…  │ 编辑 删除│ │  职称中文直传
│ │ 5  │ 李强     │ 普通外科   │ 副主任医师│ 腹腔镜…  │ 编辑 删除│ │
│ └────────────────────────────────────────────────┘ │
│                          ◀ 1 ▶   共 8 条             │
└────────────────────────────────────────────────────┘

[+ 新增医生] / [编辑] → Dialog（宽 520px）：
┌──────────────────────────────┐
│  新增医生                  ✕  │
│  医生姓名*  [________________] │  ≤50
│  所属科室*  [心血管内科   ▼]   │  下拉=GET /admin/departments 过滤 parentId 非空（仅子科室）；必选
│  职称*      [主任医师     ▼]   │  下拉三档中文：主任医师/副主任医师/主治医师
│  擅长领域   [____________]    │  textarea ≤500
│              [取消]  [保 存]   │
└──────────────────────────────┘
│  ℹ️ 挂号费由系统按职称自动定价（主任30/副主任20/主治15），无需填写 │  Dialog 底部灰色说明
```

| 元素 | 字段/行为 | 说明 |
| --- | --- | --- |
| 表格列 | `id / doctorName / deptName / title / skill` | 职称列可直接 el-tag 装饰（三档同色或分级着色，仅装饰） |
| 科室下拉 | 打开 Dialog 时拉取科室全量（复用科室接口，不分页全量参数【待对齐：pageSize 上限】），**过滤 parentId 非空的子科室**（V1.1：父分类节点不挂医生） | deptId 为空提交 → 前端拦截；4001 兜底 Message |
| 职称下拉 | 三个固定中文选项，与 CHECK 约束取值一致；**表单无挂号费字段**（费用=职称映射，拆解文档 6.5-⑥） | |
| 删除 | DELETE /{id}（逻辑删除 delmark=1，且后端同事务逻辑删其未来排班——前端无感，只需成功提示+刷新） | |
| 编辑 | 回填四字段；doctorName 允许改名（V2.1 起取消回补按 schedule_id，不依赖姓名） | |

**状态**：v-loading / el-empty / 4001 等错误 Message / 正常。

## M4 全局规则（管理端）

| 项 | 规范 |
| --- | --- |
| axios 封装 | baseURL `http://localhost:8080/api`；请求拦截器注入 `Authorization: Bearer {token}`（管理端本期无登录，可预留空实现【待对齐】）；响应拦截器：`code===200` 透传 data，否则 `ElMessage.error(message)` 并 reject；HTTP 401 → `ElMessage.warning('登录已失效')` + 跳 /401 |
| 401 提示页 | 居中卡片：「登录已失效，请联系管理员」（管理端登录为范围外，仅提示不提供输入框） |
| 网络异常 | 请求 reject 且无 response → `ElMessage.error('网络连接异常，请检查网络')` |
| 类型定义 | `src/api/` 集中定义：接口函数 + TS 类型（从 dto-contract.md 逐字段抄写）；组件禁止手写 URL/字段（规则八） |
| 加载 | 表格 v-loading；Dialog 保存按钮 loading；禁止双层 loading |
| 表单校验 | rules 与 dto-contract 校验列一致（必填/长度/枚举下拉）；后端 400 时以 message 为准展示 |
| 空态 | 表格自带 el-empty；筛选无结果同空态 |
| 刷新纪律 | 增/删/改成功后**刷新当前页**（保持 pageNum；删空当前页则 pageNum-1） |
