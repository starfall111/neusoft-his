## P1 登录页（S2 · 免登录直达页）

**数据来源**：`POST /auth/login` → `Result<LoginRespDto{token,userId,username}>`

```
┌────────────────────────────┐
│                            │
│       东软云医院            │  ← 20fp Bold，居中，上部 1/3 处
│       挂号预约              │  ← 14fp text-tertiary 居中
│                            │
│  ┌──────────────────────┐  │
│  │ 请输入用户名           │  │  TextInput，无标签行内占位
│  └──────────────────────┘  │
│  ┌──────────────────────┐  │
│  │ 请输入密码         👁 │  │  密码型，右侧明文切换图标
│  └──────────────────────┘  │
│  ┌──────────────────────┐  │
│  │        登  录         │  │  主按钮胶囊；两框任一为空→禁用
│  └──────────────────────┘  │
│                            │
│     没有账号？ 去注册 →     │  ← primary 文字链 → P2
└────────────────────────────┘
```

| 元素 | 字段/行为 | 说明 |
| --- | --- | --- |
| 登录按钮 | `POST /auth/login`，body=`LoginReqDto{username,password}` | 提交中按钮 loading 且禁点（防重复）；成功：token/userId/username 存 AppStorage → 替换到 P3（清返回栈） |
| 错误反馈 | 1002 → Toast「用户名或密码错误」；网络失败 → 固定网络文案 | message 取后端原文 |
| 校验 | 两框 @NotBlank 同口径非空；前端不校验格式 | |

**状态**：正常 / 提交中 / 业务错误 Toast / 网络错误 Toast。
**要点**：本页免登录直达；401 不会出现在本页。

## P4A 当天挂号页（V2.0 新增）

**数据来源**：`GET /quotas?deptId=&date={当天}`（契约变更 ② **已落契约** dto-contract V1.3）——按科室+日期返回医生号源行：`scheduleId / doctorId / doctorName / title / skill / timeSegment / leftQuota / registerFee`，后端按职称排序（主任→副主任→主治）、上午段在前下午段在后

```
┌────────────────────────────┐
│ ←  心血管内科        [📅排班]│  右上角唯一「排班」入口 → P5
│ [今天 · 09-08 周二] 按职称排序│
├────────────────────────────┤
│ ── 上午 ──                  │
│ ┌────────────────────────┐ │
│ │ 周建国 [主任医师]  余 30 │ │  余>10：success
│ │ 冠心病、高血压及其并发症… │ │
│ │                [挂 号]  │ │  卡片右侧按钮 → P6
│ └────────────────────────┘ │
│ ┌────────────────────────┐ │
│ │ 吴敏 [副主任医师]  余 3  │ │  1–10：warning（紧张）
│ └────────────────────────┘ │
│ ── 下午 ──                  │
│        📅 暂无号源           │  分组空态（无排班不渲染空行）
└────────────────────────────┘
```

| 元素 | 字段/行为 | 说明 |
| --- | --- | --- |
| 医生卡 | 姓名+职称标签+擅长（单行截断）+当日 `leftQuota`；**无任何时间选择** | 色阶：>10 success / 1–10 warning / 0=已满置灰不可点 |
| 挂号按钮 | 卡片右侧，携带 `scheduleId` + 医生/科室/费用展示信息 → P6 确认挂号 | 已满卡按钮与整卡均禁用（禁用优先于隐藏） |
| 排班入口 | **仅**顶栏右上角一个「排班」按钮 → P5 排班总览 | 页面内不再有其他排班查看入口 |
| 分组 | 先「上午」组后「下午」组；组内按职称排序 | 后端口径，前端不重排 |

**状态**：加载 / 整页空态「暂无号源」 / 分组空态 / 错误 Toast / 正常 / 已满禁用。
