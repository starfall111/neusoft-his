## P1 登录页（S2 · 免登录直达页）

**数据来源**：`POST /auth/login` → `Result<LoginRespDto{token,userId,username}>`

```
┌────────────────────────────┐
│                            │
│       东软云医院            │  ← 20fp Bold，居中，上部 1/3 处
│       挂号预约              │  ← 14fp text-tertiary 居中
│                            │
│  ┌──────────────────────┐  │
│  │ 请输入用户名           │  │  TextInput，无标签行内占位
│  └──────────────────────┘  │
│  ┌──────────────────────┐  │
│  │ 请输入密码         👁 │  │  密码型，右侧明文切换图标
│  └──────────────────────┘  │
│  ┌──────────────────────┐  │
│  │        登  录         │  │  主按钮胶囊；两框任一为空→禁用
│  └──────────────────────┘  │
│                            │
│     没有账号？ 去注册 →     │  ← primary 文字链 → P2
└────────────────────────────┘
```

| 元素 | 字段/行为 | 说明 |
| --- | --- | --- |
| 登录按钮 | `POST /auth/login`，body=`LoginReqDto{username,password}` | 提交中按钮 loading 且禁点（防重复）；成功：token/userId/username 存 AppStorage → 替换到 P3（清返回栈） |
| 错误反馈 | 1002 → Toast「用户名或密码错误」；网络失败 → 固定网络文案 | message 取后端原文 |
| 校验 | 两框 @NotBlank 同口径非空；前端不校验格式 | |

**状态**：正常 / 提交中 / 业务错误 Toast / 网络错误 Toast。
**要点**：本页免登录直达；401 不会出现在本页。

## P5 排班页（S6）

**数据来源**：`GET /schedules?doctorId=` → `List<ScheduleRespDto>`（近 7 天，workDate 升序）

```
┌────────────────────────────┐
│ ←  选择就诊时间             │
│    周建国 · 心血管内科（小字） │
├────────────────────────────┤
│ ┌────────────────────────┐ │
│ │ 09-09 周三 · 上午        │ │  workDate(MM-dd 周X) + timeSegment
│ │ 余 30 / 共 30   [预 约]  │ │  leftQuota>10：success「余 N 预约」
│ └────────────────────────┘ │
│ ┌────────────────────────┐ │
│ │ 09-10 周四 · 上午        │ │
│ │ 余 3 / 共 20    [余 3 预约]│ │  1≤leftQuota≤10：warning 提示紧张
│ └────────────────────────┘ │
│ ┌────────────────────────┐ │
│ │ 09-11 周五 · 上午        │ │
│ │ 余 0 / 共 30    [已 满]  │ │  leftQuota=0：整卡置灰不可点
│ └────────────────────────┘ │
└────────────────────────────┘
```

| 元素 | 字段/行为 | 说明 |
| --- | --- | --- |
| 排班行 | `workDate`（格式化 MM-dd + 周几）、`timeSegment`、`leftQuota`/`totalQuota` | 点击有效排班 → P6，携带 `scheduleId` + 医生/科室/费用展示信息 |

## P10 全局组件与守卫

| 组件 | 规范 |
| --- | --- |
| withLogin 守卫 | 进入 P3 入口页、P6、P7、P8、P9 前检查 AppStorage.token；无 → Toast「请先登录」→ P1；放行清单与后端拦截器（拆解文档 4.1）一致 |
| Toast | 统一居中短提示；业务错=后端 message；网络错=固定文案；不出现技术性文案（如 HTTP 状态码） |
| 空态 | 占位图 + 文案（必要时 + 动作按钮），见各页 |
| 退出登录（S3） | P3 顶栏入口 → AlertDialog「确认退出登录？」→ 清 AppStorage token → P1；返回键验证受控页均不可达 |
| 复制 | 订单号一键复制到剪贴板，Toast「已复制」 |
| 网络层 | axios 拦截器统一注入 Authorization、统一错误 Toast（member-d/D02 实现，页面不重复处理） |
